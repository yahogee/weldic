# weldic

복지 용어와 사업안내·법령 문서를 한 번에 찾아 주는 검색 앱입니다.
단어를 입력하면 **용어 카드**(원문 + 쉬운 풀이)와 **문서 속 해당 쪽**이 함께 나옵니다.

> 이 사이트는 공개 주소입니다. **공개해도 되는 자료만** 올리세요. (개인정보, 내부 문서, 민원인 사례는 절대 올리지 않습니다.)

---

## 1. 폰에 앱으로 설치하기 (안드로이드 · 크롬)

1. 크롬으로 앱 주소를 엽니다. (`https://yahogee.github.io/weldic/`)
2. 오른쪽 위 **⋮ (점 세 개)** 를 누릅니다.
3. **"홈 화면에 추가"** 또는 **"앱 설치"** 를 누르고 **설치**를 누릅니다.
4. 홈 화면에 생긴 **weldic** 아이콘으로 열면 됩니다. (한 번 열어 본 뒤에는 인터넷이 없어도 열립니다.)

## 2. 쓰는 법

- 맨 위 입력창에 단어를 씁니다. 예: `부양의무자`, `이의신청`, `소득인정액`
- 초성도 됩니다. 예: `ㅅㄱㄱㅈ` → 수급권자
- 결과를 누르면 **그 자리에서 내용이 펼쳐집니다.** 다른 결과를 누르면 앞의 것은 닫힙니다.
- PDF 결과에서 **"원본 PDF에서 보기"** 를 누르면 해당 쪽이 열립니다.
- 오른쪽 위 **"자료 목록"** 에서 어떤 자료가 들어 있고 언제 갱신됐는지 볼 수 있습니다.

## 3. 자료 올리기 (GitHub 웹에서, 코딩 필요 없음)

1. GitHub에서 이 저장소(`yahogee/weldic`)를 엽니다.
2. **`library`** 폴더를 누릅니다.
3. 오른쪽 위 **Add file → Upload files** 를 누릅니다.
4. PDF 파일을 화면에 끌어다 놓습니다. (여러 개 가능)
5. 아래 초록색 **Commit changes** 버튼을 누릅니다.
6. 2~3분 기다린 뒤 앱을 열면 **"자료 목록"** 에 새 자료가 보입니다. 안 보이면 앱을 닫았다 다시 열어 보세요.

**올릴 수 있는 것**
- 글자가 들어 있는 PDF (파일 하나당 25MB 이하)
- 한글(hwp) 파일은 **PDF로 저장**해서 올립니다.
- 글자가 없는 스캔본(사진으로 된 PDF)은 검색되지 않습니다.
- 법령 원문은 `library/법령` 폴더에 `.txt` 파일로 올립니다. 첫 줄은 `# 제목` 으로 쓰고, 조문은 `제1조 목적` 처럼 한 줄에 조문 번호로 시작하게 씁니다.

**자료 지우기:** `library` 폴더에서 파일을 열고 오른쪽 위 휴지통 아이콘 → **Commit changes**.
**자료를 전부 새로 바꾸기:** 전부 지우고 새로 올려도 앱 화면은 그대로 동작합니다. 자료가 하나도 없으면 "자료가 없어요"라고 나옵니다.

## 4. 문제가 생기면

- 저장소 위쪽 **Actions** 탭에서 가장 최근 항목에 빨간 ✕ 가 있으면 자료 처리에 실패한 것입니다. **앱에는 직전의 정상 버전이 그대로 남아 있으니** 당황하지 마세요. 방금 올린 파일 이름과 함께 알려 주세요.
- 앱이 예전 내용을 보여 주면 앱을 완전히 닫았다가 다시 여세요.

## 5. 처음 한 번만 하는 설정 (개발 담당)

저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다. 이후에는 파일을 올릴 때마다 자동으로 반영됩니다.

## 개발자 메모

| 위치 | 역할 |
|---|---|
| `library/` | 검색 대상 원본 문서 (PDF, TXT). 여기에 파일을 넣고 빼는 것이 자료 관리의 전부 |
| `terms/` | 용어 카드 (JSON). 카드는 원문 인용이 문서에서 실제로 확인돼야 "원문 대조됨"이 됨 |
| `app/` | 화면 (HTML/CSS/JS). 문서 내용은 코드에 들어 있지 않고 `data/`를 읽어서 보여 줌 |
| `tools/build.py` | `library/`와 `terms/`를 읽어 `site/`(배포 결과물)를 만듦 |
| `.github/workflows/deploy.yml` | 파일이 올라오면 자동으로 빌드 + 배포 |

로컬 빌드: `python3 tools/build.py` (PDF 추출에 `pdftotext`(poppler) 필요). `--strict` 를 붙이면 카드 검증 실패 시 오류로 종료합니다.

**용어 카드 필드:** `id`, `term`, `aliases`, `system`, `source{doc,label}`, `quote`(원문 그대로), `gloss`(AI 작성 풀이, 숫자 금지), `basis_date`, 선택 `confirmed`(사람이 확인했을 때 true).
선택 필드 `related`: 같이 알아야 할 카드의 `id` 목록. 카드 아래 "같이 알아야 할 용어" 버튼으로 나타나며, 없는 id가 있으면 빌드가 알려 줍니다.

**카드 추가 방법:** `terms/` 폴더의 JSON 파일에 카드 항목을 더하거나 새 `.json` 파일을 올립니다(파일 이름은 자유). `quote`는 `library/` 문서에 실제로 있는 문장을 그대로 붙여 넣고, `source.label`은 쪽(예: `57쪽`)이나 조(예: `제7조`)로 씁니다. 올리면 자동으로 빌드·배포되고, 원문과 안 맞으면 "검수 전"으로 표시됩니다.

## 출처

- 보건복지부 「사업안내」 (공공누리 출처표시 · 원문 변경 없이 인용)
- 국가법령정보센터 법령 원문
- 용어 카드의 "쉬운 풀이"는 AI가 작성한 참고용이며, 업무 판단과 민원 안내는 반드시 원문을 기준으로 합니다.
